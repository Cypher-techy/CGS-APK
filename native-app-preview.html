Why no emulator? This sandbox has no /dev/kvm, no virtualisation flags and ~1.6 GB RAM, so Android can only be software-emulated — it wouldn't boot in usable time.

To run the real APK: install it on any Android phone (allow "install unknown apps"), or drop it into Appetize.io / BrowserStack App Live / Firebase Test Lab to use a device in the browser.
